# ModelScope 小模型十场景实验

本轮复用既有十场景全部 3516 条提示，检验“辅助抽取字段改变来源值误用，且受关系表达调节”。不新增数据筛选，不把任何误填都视为核心现象复现，不进行内部干预。

模型：Qwen2.5-1.5B、Qwen2.5-3B、Qwen3-4B、Gemma-2-2B、Phi-4-mini、Llama-3.2-3B，均从 ModelScope 下载原始指令权重。实际参数量由运行器核验小于 8B。六个模型共 21096 条正式生成，技术冒烟样本另存、不加入分母。

每模型覆盖公司、人物、活动、商品、科研成果、物流、影视、文物、图书、采购场景。沿用原始提示、字段顺序和金标准。原生聊天模板，Qwen3 关闭思考；BF16、贪心、批量 16、最大 128 新 token，不重跑截断，不增加关系提示或示例。

两卡独立队列；一项技术失败会记录并继续下一模型。全部模型保留正式输出与 token、输入提示、权重哈希及依赖版本。严格评分与仅去除完整外层代码围栏的内容评分并列报告。不同语言能力、格式遵循能力及明确证据诊断的错误，作为可解释性限制，不冒充阴性复现。

关键文件：protocol.json 为运行前设置；data/lock.json 为设置、提示及核心代码哈希；results/*_environment.json 为模型环境；results/*_status.json 为实时进度；results/*_summary.json 为分条件与模板统计；results/*.jsonl 为完整自然生成。results/report.md 和 report.html 为滚动汇总。

公司场景沿用原公司验证规则，新增九场景沿用各自探索规则，不将二者直接汇总为统一成功率。主要查看每模型内部 B/D 和表达交互；所有模型使用的是同一历史材料，不能称为全新验证集。跨系列复现范围比简单计数通过模型数更重要。
