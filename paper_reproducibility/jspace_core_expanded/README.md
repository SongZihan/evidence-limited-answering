# 核心独立验证扩充

本轮检验原有公司场景的行为发现和冻结低维干预能否推广到新材料。运行前已锁定 `protocol.json` 与 `data/lock.json`，不根据新增结果修改模板、重算子空间或挑选层。

## 样本设计

每模型使用24个新措辞模板，每模板4组公司与城市组合，分别设置总部缺失、明确总部、交换城市关系三种证据条件，以及分句和直接连接两种表达。每段正文分别要求输出“总部城市、办公城市”（B）和“总部城市、成立年份”（D）。B、D正文完全相同，总部字段始终先输出。

因此，每模型有1152次自然生成，每个实验单元96例。统计上的模板分组是24组，不能将1152次生成视为1152个相互独立的样本。与旧独立验证相比，模板数和每单元例数均扩大6倍。

保留原城市词汇，用未进入旧探索与验证材料的城市配对，并平衡城市角色；新增公司名与措辞。材料包括年鉴、报告、场所记录等表述，但仍属于人工构造短文本，不等同于真实文档抽样。全部新增模板均保留，未按模型输出筛选。

## 模型与干预

|模型|原冻结配置|设备|
|---|---|---|
|Qwen3.5-2B|零起算第22层、一维|GPU 0|
|Qwen3-8B|零起算第33层、四维|GPU 1|

沿用历史检查点、BF16、非思考模式和单条贪心生成。每次最多128个新token，截断作为失败保留，不自动延长。

干预覆盖所有分句材料（每模型288组B/D配对）。比较同一前缀未干预继续生成、B→D低维替换、D→B反向替换、完整状态替换及原随机子空间；逐例检查自替换是否保持生成token完全一致。同一事实及证据条件配对供体，不跨证据条件替换。

不重新训练J-lens，也不新增内部逐层读数；本轮重点扩充行为和因果验证。此前逐层观察仍属于原样本结果。

## 分析和文件

自然行为使用严格协议评分；干预主结果沿用图8的内容评分，并保留严格评分。未定位样本保留在计划分母，不计作修复。主要行为交互和留空增益采用模板配对bootstrap，其余以模板计数和错误转移为主。具体描述性标准见运行前协议。

- `data/jobs.json`：材料、提示词、条件、金标准。
- `data/pairs.json`：B/D配对。
- `data/*basis.pt`：原冻结与随机基。
- `results/<model>/pairs.jsonl`：完整逐条输出、token、边界与评分。
- `results/<model>/states_X*.pt`：配对内部状态。
- `results/<model>/environment.json`：模型和代码校验信息。
- `results/report.md`、`report.html`、`summary.json`：完成后汇总。
- `results/template_results.csv`：全部模板的行为及干预变化。

旧验证集与本轮新增结果分别报告，不合并成预先独立的验证集；本轮也不重新拟合参数。
